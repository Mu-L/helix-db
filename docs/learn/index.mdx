The learning center explains the ideas behind modern data infrastructure for AI
applications: how graph databases model relationships, how vector and full-text search
rank results, how agents remember, and why storage architecture decides cost at scale.
Each page answers one question from first principles and ends with how HelixDB
approaches it.

## Build with HelixDB

HelixDB is an open-source graph database with native vector search and BM25 full-text
search, built on object storage. Start a local instance in a few commands with
[Get started](/database/helix-db/start-here/quickstart), or read the
[introduction](/database/helix-db/start-here/introduction).
