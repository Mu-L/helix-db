---

<div className="flex flex-wrap gap-2"><Badge color="gray" size="sm">Reference</Badge></div>

```bash
helix status [INSTANCE]
```

Local status comes from the configured Docker/Podman runtime. Cloud status uses the WorkOS session
and fetches the linked tenant or dedicated cluster; cluster status also includes current topology.
